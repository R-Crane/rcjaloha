# Résumé — rcjaloha.com

Personal résumé site for me - Riley Crane-Jio, built as a static single-page
site styled as a dark terminal window.

## Stack

Plain HTML, CSS, and JavaScript — no build tools, no dependencies.

## Structure

```
index.html    — content + structure
styles.css    — design tokens + layout
script.js     — hero typing effect, LinkedIn link toggle, footer year
CNAME         — custom domain config for GitHub Pages
```

## Local development

Just open `index.html` in a browser, or serve the folder with any
static file server.
